Aerra Properties WEBSITE SETUP

1. Install VS Code.
2. Extract this ZIP.
3. Copy your logo image into the folder and rename it 'logo.png'.
4. Open the folder in VS Code.
5. Create a Google Sheet named Leads.
6. Open Extensions > Apps Script and paste apps_script.js code.
7. Deploy as Web App and copy the URL.
8. Replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE in script.js.
9. Open index.html to test locally.
10. Upload project to GitHub and deploy using Netlify.
